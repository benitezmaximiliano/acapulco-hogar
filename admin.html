Conectar con GitHub

Esto se hace una sola vez en cada computadora o celular. El permiso queda guardado solo en este navegador.

  1. Entrá a github.com/settings/personal-access-tokens/new (con la cuenta dueña del sitio).
  2. Ponele un nombre (ej. “Panel Acapulco Hogar”) y elegí vencimiento de 1 año.
  3. En Repository access elegí Only select repositories y marcá acapulco-hogar.
  4. En Permissions → Repository permissions poné Contents: Read and write.
  5. Tocá Generate token, copiá el código (empieza con github_pat_) y pegalo acá abajo.
